Ogma for Windows — preview

Extract this ZIP to a folder and launch Ogma.exe. Keep the Unicode license with
the app. The .NET runtime is included; no separate installation is needed.
Ogma runs in the notification area (possibly behind the ^ arrow). Double-click
its icon for Settings. Close Settings to keep Ogma running; choose Quit Ogma
from the icon menu to exit.

Type : to browse emoji or :joy to search. Type / to browse saved shortcuts,
or /date for today's date. Use arrows, Enter, Escape, or click a suggestion.
Create shortcuts in Settings > Shortcuts. Change date format and grid/list
layout in Settings > General.

Shortcuts, preferences, and emoji usage are saved locally in %LOCALAPPDATA%\Ogma.
No typing history is saved. Ogma does not use the clipboard or upload data.

This preview is unsigned. Smart App Control can block it completely, with no
per-app allow exception. It requires a signed release from the publisher to
address that block. SmartScreen warnings are a separate Windows feature.

Ogma cannot insert into apps running as administrator or into the
Windows secure desktop. Some editors, games, and IMEs do not support simulated
Unicode typing or expose a usable caret. Password fields are excluded when
Windows identifies them as protected; unavailable accessibility providers
disable suggestions for that field. Ogma falls back to the focused field's
center when no caret is exposed. Emoji glyph availability depends on Windows.

Windows updates are manual: https://github.com/raulpop8/ogma/releases
This preview needs manual Windows testing before a public release.
