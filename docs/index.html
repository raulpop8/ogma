Make yourself at home.

One Ogma, built natively for each platform. Choose your download and set it up once.

On your Mac

  1. Download the signed, notarized DMG and drag Ogma into Applications.
  2. Launch Ogma and grant Accessibility access in System Settings → Privacy & Security.
  3. Open Settings from the Ogma menu bar icon. Check that Keyboard listener says Ready.
Download for macOS

Requires macOS 14 or later. Closing Settings keeps Ogma running in the menu bar.

On your Windows PC

  1. Install Ogma Typing by Raul Pop from Microsoft Store.
  2. Launch it from Start. Double-click the Ogma icon in the notification area to open Settings.
  3. Keep Ogma enabled and try a shortcut in an ordinary, non-administrator text editor.
Get Ogma on Microsoft Store

Requires Windows 11. Supports x64 and ARM64 PCs. The tray icon may be behind the hidden-icons arrow.

Updates, without the guesswork.

Mac updates in Ogma

Choose Check for Updates… from the Ogma menu. Ogma uses Sparkle to install signed Mac releases hosted on GitHub.

Windows updates in the Store

Microsoft Store delivers published updates according to your PC's update settings. You can also check for updates directly in the Store.

Are the Mac and Windows editions the same app?

They are two native editions of Ogma, sharing the emoji catalog and the same core idea. Their interfaces and platform integrations are not yet identical. Each installation keeps its own shortcuts and preferences; they do not sync between devices.

Does Ogma work in every text field?

Compatibility depends on the editor and the accessibility information it provides. Password fields are excluded when identified. On Windows, insertion into apps running as administrator is unavailable. Custom editors, terminals, and remote desktops may behave differently. If a replacement is incomplete, check your text before retrying.

Why does Windows “View releases” open GitHub?

That command currently opens the project's release history. It does not update the Windows app. Use Microsoft Store for Windows installation and updates; the GitHub download currently serves the Mac edition.

Your shortcuts stay yours.

Emoji search works offline. Saved text shortcuts, preferences, and emoji usage stay on your device. Ogma does not save typing history, use the clipboard for insertion, or upload your text.

Ogma uses your active shortcut query and editor accessibility information to place suggestions and insert the result. It does not read document contents. It has no advertising or analytics service.
